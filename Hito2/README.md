## Environment and command

Python 3.10.12 (versions in [`requirements.txt`](requirements.txt), also stored in notebook §10 (run record)). From the
**repository root**:

```bash
python -m venv .venv && source .venv/bin/activate      # Windows: .venv\Scripts\activate
pip install -r Hito2/requirements.txt
jupyter nbconvert --to notebook --execute --inplace Hito2/hito2_experiment.ipynb
```

The notebook stops with an assertion if any check fails (row counts, race split, unique/common `pair_id`s, leakage checks,
reference reproduction, pooled-MAE arithmetic, SHAP reconstruction). `RANDOM_SEED = 414` is used for the truncation-check
sample and the bootstrap; OLS itself has no randomness. It also reuses `../Hito1/outputs/validation_reference_predictions.csv`
to show that the Hito 1 reference is reproduced row by row.
